# Vplugins 新手快速上手

这是一份给第一次使用 Vplugins 的说明。跟着下面的步骤操作，你可以在 Photoshop 中把画布或选区交给 AI 处理，再把结果放回原文件。

> 已经会使用 Vplugins、需要配置工作流或排查问题时，请阅读 [完整功能介绍与使用说明](使用介绍.md)。

## Vplugins 能做什么？

Vplugins 是 Photoshop 里的 AI 工作流助手。它不会取代 Photoshop，而是帮你把“把图片交给 AI 处理，再拿回 Photoshop”这段流程变得更简单。

你可以用它：

- **根据提示词生成或修改图片**：例如输入“将背景改为日落海边”。
- **局部修改画面**：先在 Photoshop 框选人物、背景或物体，再只处理该区域。
- **使用参考图**：上传风格图、产品图或人物图，让结果参考它们。
- **一次生成多张结果**：从多个版本中挑选更满意的一张。
- **把结果放回原 Photoshop 文档**：结果会作为新图层或智能对象放回，原图不会被直接覆盖。

具体可用的 AI 功能由你在 Vplugins 中启用的功能决定；不同功能支持的提示词、参考图、裁剪、强度和输出效果可能不同。

## 开始前，先确认三件事

1. 已安装并启动 **Vplugins 桌面端**。
2. 已在 Photoshop 中安装、加载与桌面端版本一致的 **Vplugins Photoshop Bridge**。
3. 已打开一个 Photoshop 文档，并从 Photoshop 的 Vplugins 菜单打开 **Prompt Bar**。

如果 Prompt Bar 显示“PS 未连接”，先不要开始生成；请确认 Photoshop 已启动、Bridge 已加载，且桌面端与 Bridge 版本一致。

## 第一次生成：四步完成

### 1. 选择功能

点击 Prompt Bar 最左侧的 **`+`**，从菜单中选择想使用的功能。

新手建议先选择已经启用的官方功能，或由团队管理员准备好的功能。若菜单为空，请参见本文的[“看不到功能怎么办？”](#看不到功能怎么办)。

### 2. 输入你想要的效果

在中间输入框写清楚“改什么”和“想要什么样子”。例如：

```text
把桌面的背景替换为明亮整洁的北欧客厅，保留产品外观和文字不变。
```

提示词越具体，结果通常越接近预期。可以写明主体、场景、风格、光线、颜色，以及必须保留的内容。

### 3. 按需选择运行选项

Prompt Bar 右侧可用的选项包括：

| 选项 | 什么时候使用 |
| --- | --- |
| 参考图按钮 | 想让结果参考某张图片的风格、构图或主体时使用。最多可添加 5 张。 |
| 裁剪按钮 | 只想修改 Photoshop 选区内的内容时使用。请先在 Photoshop 创建选区。 |
| 强度 | 功能支持时，用来控制原图保留程度或修改幅度；不确定时先使用默认值。 |
| `1k / 2k / 4k` | 选择输出分辨率；分辨率越高，耗时和资源消耗通常越多。 |
| `1 / 2 / 3 / 4` | 选择一次生成的版本数量；第一次建议选 1 张。 |

### 4. 运行并放回 Photoshop

1. 点击最右侧的圆形运行按钮。
2. 等待 Vplugins 读取图片、上传并生成结果。
3. 在结果区查看生成的图片，选中想保留的结果。
4. 点击 **发送到PS**，将结果放回原 Photoshop 文档。

运行中，圆形按钮会显示停止方块；再次点击可请求取消任务。请不要在任务运行期间关闭当前 Photoshop 文档。

## 两个最常用的进阶操作

### 只修改图片的一部分

例如，只想替换天空、不想影响人物：

1. 在 Photoshop 用任意选区工具框选天空。
2. 在 Prompt Bar 打开 **裁剪**。
3. 输入提示词，例如“晴朗蓝天，少量白云”。
4. 运行并将满意的结果发送回 Photoshop。

开启裁剪后，Vplugins 会记录选区的位置，尽量把结果对齐放回原区域。

### 让结果参考一张图片

例如，想让产品海报参考某张样图的配色：

1. 点击图片按钮，添加参考图。
2. 输入提示词，说明希望参考什么，例如“参考图片的柔和蓝紫色调和极简排版”。
3. 运行生成。

参考图是帮助 AI 理解方向的素材，不保证逐像素复制。请确保你拥有参考图及素材的使用权。

## 功能从哪里来？新手该选哪一种？

| 功能来源 | 适合谁 | 开始方式 |
| --- | --- | --- |
| **Vplugins 官方功能** | 想尽快开始、不想配置工作流的用户 | 在“设置 → 用户登录”登录后，到“功能展示”启用可用功能。 |
| **RunningHub 功能** | 想使用云端 AI 工作流的用户 | 在“设置 → RunningHub”填写 API Key，再到“功能录入”导入 App ID 或 WebApp ID。 |
| **本地 ComfyUI 功能** | 已会使用 ComfyUI、希望本机运行模型的用户 | 在“设置 → 本地 ComfyUI”配置并启动 ComfyUI，再扫描兼容的 workflow。 |

第一次使用时，优先选择官方功能或团队已经配置好的功能。RunningHub 会使用真实账号并可能产生余额消耗；本地 ComfyUI 则需要预先安装模型和工作流。

## 看不到功能怎么办？

按以下顺序检查：

1. 打开 **设置 → 功能展示**，确认至少有一个功能已启用。
2. 若使用官方功能，确认已经登录，且当前套餐或权限允许使用该功能。
3. 若使用 RunningHub，确认 API Key 已验证，并且 App ID / WebApp ID 已成功导入。
4. 若使用本地 ComfyUI，确认 ComfyUI 已启动，workflow 目录已扫描且工作流没有报错。
5. 回到 Prompt Bar，再点击 `+` 查看功能菜单。

## 常见问题

### 点击运行后提示“PS 未连接”

重新确认 Photoshop 已打开，且 Vplugins Photoshop Bridge 已加载。开发环境请在 Adobe UXP Developer Tool 中点击 Load 或 Reload。

### 结果生成了，却无法放回 Photoshop

不要关闭任务开始时的 Photoshop 文档。恢复 Bridge 连接后，选中结果并再次点击 **发送到PS**。

### 想改局部，结果却改了整张图

先在 Photoshop 创建选区，再开启 Prompt Bar 的裁剪按钮；只创建选区但没有打开裁剪，通常仍会按整张画布处理。

### 任务运行失败或时间太长

先重试一次较低分辨率、1 张输出的任务。若使用 RunningHub，请检查余额、API Key、App 是否仍可用；若使用本地 ComfyUI，请在设置的日志页查看启动错误。

## 使用时请注意

- 结果会以新图层或智能对象方式放回，建议先保留原始图层，便于比较和撤销。
- 不要把 RunningHub API Key 发给他人，也不要放进提示词或截图中。
- 云端生成会上传当前画布、选区或参考图；处理客户素材前，请确认所选服务符合你的隐私和授权要求。
- 模型、工作流和参考素材的版权与使用许可，由使用者自行确认。

需要更完整的安装、工作流配置、更新和错误码说明，请继续阅读 [完整功能介绍与使用说明](使用介绍.md)。
